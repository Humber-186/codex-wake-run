# 在唤醒系统提示中加入命令耗时

## 预期目标

- 记录 wake-run 执行命令的墙钟、用户态和系统态 CPU 耗时。
- 将多项耗时写入完成事件，并展示在返回原 Codex 会话的系统提示中。
- 覆盖直接执行、失败、重试和补发路径，保持文档契约与实际消息一致。

## 行进状态

- 已完成：命令耗时已记录、持久化并加入唤醒系统提示。

## 最终已交付成果

- worker 使用单调时钟记录所有平台的墙钟耗时，并在 POSIX 平台使用子进程资源统计记录每次执行尝试的 CPU 耗时；Windows 省略无法可靠取得的进程树 CPU 指标。
- completion JSON 保存累计 wall/user/sys 指标，每次尝试也保存独立指标。
- 原 Codex 会话收到的系统提示新增 `wall`、`user` 和 `sys` 字段。
- 相关测试和中英文 Skill 文档已同步更新。
